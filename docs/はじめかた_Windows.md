# はじめかた（Windows・初心者向け手順）

Windows PCで動作確認するための手順です。コードを書く必要はありません。
順番どおりに進めれば動きます。所要時間の目安は30分〜1時間（多くはインストールの待ち時間）です。

---

## 事前に知っておくこと

- **Docker Desktop のインストールに管理者権限が必要**です。会社PCで入れられない場合は、情シス（IT担当）に相談してください。
- **最初のビルド（組み立て）時だけインターネットが必要**です（部品のダウンロードのため）。
  一度組み立てた後の運用は、ネットが無くても動きます。
- コマンドは **PowerShell**（ウィンドウズの黒い画面）に貼り付けて実行します。

---

## ステップ1: Docker Desktop を入れる

1. ブラウザで「**Docker Desktop Windows ダウンロード**」を検索し、公式サイト(docker.com)から
   `Docker Desktop for Windows` をダウンロードします。
2. ダウンロードした `Docker Desktop Installer.exe` を実行し、画面の指示どおり進めます
   （WSL2 を使う設定はそのままでOK）。
3. インストール後、PCを再起動します。
4. スタートメニューから **Docker Desktop を起動**します。
   画面右下やタスクバーの**クジラのアイコン**が「Running（動作中）」になればOKです。
   ※初回は起動に数分かかることがあります。

> Docker Desktop が起動していないと、後のコマンドは動きません。必ず起動しておいてください。

---

## ステップ2: コード（プログラム）をPCに置く

GitHubからダウンロードします。

1. ブラウザでこのリポジトリのページを開きます。
2. 画面左上の**ブランチ選択**（枝のマーク）を押し、`claude/project-management-db-gui-9pewq5` を選びます。
3. 緑色の「**Code**」ボタン → 「**Download ZIP**」でZIPをダウンロードします。
4. ダウンロードしたZIPを、分かりやすい場所（例: デスクトップ）に**展開（すべて展開）**します。
   - 展開すると `project-management-table-...` というフォルダができます。

---

## ステップ3: 設定ファイルを作る

1. ステップ2で展開したフォルダを開きます。
2. フォルダの**何もない所で「Shift + 右クリック」→「PowerShell ウィンドウをここで開く」**
   （または「ターミナルで開く」）を選びます。黒い画面が開きます。
3. 次の3行を、1行ずつコピーして貼り付け、Enterで実行します。

```powershell
Copy-Item .env.example .env
$key = [guid]::NewGuid().ToString('N') + [guid]::NewGuid().ToString('N')
(Get-Content .env) -replace 'please-change-this-to-a-long-random-string', $key | Set-Content .env
```

これで秘密鍵が自動で安全な値に置き換わります。
（同じPCだけで試すなら、他の設定はそのままでOKです。）

---

## ステップ4: 起動する

同じPowerShellの画面で、次を実行します。

```powershell
docker compose up -d --build
```

- 初回は部品のダウンロードと組み立てで**数分かかります**（コーヒーでも飲んでお待ちください）。
- 「done」や「Started」などが表示され、プロンプトが戻ってくれば起動完了です。

---

## ステップ5: 最初の管理者アカウントを作る

続けて次を実行します。

```powershell
docker compose exec web flask create-admin
```

- 「管理者のログインID」→ 例: `admin`
- 「氏名」→ 例: `管理者太郎`
- 「パスワード」→ 8文字以上（画面には表示されませんが入力されています）
- 「パスワード（確認）」→ 同じものをもう一度

「管理者 '…' を作成しました。」と出れば成功です。

---

## ステップ6: ブラウザで開く

ブラウザのアドレス欄に次を入力します。

```
https://localhost
```

- **「この接続ではプライバシーが保護されません」等の警告**が出ます。これは想定どおりです
  （社内専用の証明書のため）。「**詳細設定**」→「**localhost にアクセスする（安全ではありません）**」を選んで進みます。
- ログイン画面が出たら、ステップ5で作ったIDとパスワードでログインします。

### 試してみること
- 上部メニュー「ユーザー管理」→「＋ ユーザーを登録」で、テスト用ユーザーを作る
  → 初期パスワードが表示されるのでメモ
- 一度ログアウトし、そのユーザーでログイン → 初回パスワード変更を体験する

---

## 終わり方・もう一度動かすとき

```powershell
docker compose down     # 停止
docker compose up -d    # もう一度起動（2回目以降は速いです）
```

入力したデータは `data` フォルダの中のファイルに保存され、停止しても消えません。

---

## うまくいかないとき

| 症状 | 対処 |
|------|------|
| `docker : ...認識されません` | Docker Desktop が起動していません。クジラアイコンが Running か確認。 |
| `docker compose up` でエラー | Docker Desktop の起動を待ってから再実行。 |
| ブラウザで開けない | `https://localhost` になっているか（`http` ではなく `https`）。少し待って再読み込み。 |
| ポートが使用中 | `.env` の `HTTPS_PORT` を `8443` などに変え、`https://localhost:8443` で開く。 |

困ったら、画面に出たエラー文をそのまま伝えていただければ対応します。
